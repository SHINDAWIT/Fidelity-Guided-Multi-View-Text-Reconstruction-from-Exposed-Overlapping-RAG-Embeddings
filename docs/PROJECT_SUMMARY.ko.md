# 중첩 임베딩 복원 결과의 선택·결합과 변경 영향 검증

**원래 논문 제목:** Fidelity-Guided Multi-View Text Reconstruction from Exposed Overlapping RAG Embeddings  
**연구 상태:** ICISC 2026 투고·심사 중

### 해결하려던 문제

노출된 중첩 RAG 임베딩을 기존 모델로 각각 역복원하면 같은 원문 부분에 여러 출력이 생기지만, 삽입·삭제 오류로 위치가 어긋나 단순 연결 시 중복과 경계 오류가 발생했습니다. 이 연구에서는 기존 모델의 여러 출력 중 어떤 결과를 선택하고 어떻게 결합할지 다뤘습니다.

### 본인 담당 작업

연구를 직접 수행하며 기존 Vec2Text의 입력·추론 구조를 확인하고, 복원 결과의 선택·결합과 비교 평가를 다뤘습니다. 입력 표현 차이와 복원 오류를 구분하고, 결합 규칙 변경이 복원율과 오류 유형에 미치는 영향을 분석했습니다. 공개 사전학습 모델의 후보 생성·교정과 기존 임베딩 일치도 점수를 활용했으며, 프로젝트에 추가된 입력 검증·결합·평가 처리를 중심으로 연구했습니다.

### 핵심 분석·구현 사례

- **입력 조건 검증:** 전체 문서의 token slice와 해당 문자열을 독립적으로 다시 토큰화한 결과가 달라지면, 입력 변화와 복원 오류가 섞이는 문제를 분석했습니다. 프로젝트의 검증 구조에서는 두 결과의 토큰 ID 일치 여부와 31개 내용 토큰+종료 토큰(EOS)이 모델의 32개 입력 위치를 충족하는지 검사했습니다. 조건을 통과한 입력을 선별해 평가 범위를 통제했습니다.
- **중첩 결과 선택·결합:** 프로젝트의 추가 결합 로직을 바탕으로, 고정 좌표에서 앞쪽 출력을 우선하는 규칙과 기존 cosine 점수가 높은 출력을 선택하는 규칙을 비교했습니다. 동률·세 구간이 겹치는 위치는 앞쪽 출력을 택하고, 선택한 짧은 출력의 빈 위치는 생략하는 조건을 유지했습니다. 위치 어긋남에 대응하는 누적 출력 끝부분과 다음 출력 앞부분의 편집 거리 정렬형 결합도 비교했습니다.
- **변경 영향 검증:** 복원율과 삽입·삭제·치환·총 편집량·구간 완전일치를 분리해 검토했습니다. 결합에는 복원 결과·점수·알려진 구간 배치만 사용했고, 정답 원문을 사용하는 사후 평가·진단과 구분했습니다.

### 대표 결과와 해석 범위

Natural Questions의 동일한 60개 평가 구간에서 구간당 136개, 총 8,160개 정답 토큰 위치를 평가했습니다. 구간마다 같은 8개 복원 결과와 고정 좌표·길이 처리를 유지하고 선택 규칙만 바꿨을 때, **복원율 95.87%→98.59%(+2.72%p), 총 편집량 415→137개**를 확인했습니다. 정확히 복원한 정답 위치는 222개 증가했습니다.

정렬형 결합은 고정 좌표 방식보다 16개 위치를 더 복원했지만, 삽입은 22→41개, 총 편집량은 137→140개로 늘고 완전일치 구간은 38/60→35/60으로 줄어 상충관계를 확인했습니다. 이 비교는 경계 추정·길이 처리도 달라지는 전체 방식 비교로 해석했습니다.

선택 규칙 비교는 동일 표본의 사후 탐색 분석이며, 복원율은 문서 전체 완전 복원율과 구분했습니다. 결과는 특정 GTR/Vec2Text 모델과 토큰화가 안정적인 영어 구간에 한정해 해석했습니다.

### 실제 사용 기술

Python(입력·결합·평가), Vec2Text(기존 역복원), PyTorch 기반 GPU 추론(CUDA 환경), Transformers·tokenizers(토큰화·입력 검증), Hugging Face datasets(평가 자료 로드), NumPy·YAML·JSON(배열·설정·결과 관리), Linux(실험 실행 환경)를 사용했습니다.
