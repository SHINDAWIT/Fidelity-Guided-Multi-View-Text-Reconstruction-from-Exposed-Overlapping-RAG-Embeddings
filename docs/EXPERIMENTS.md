## 공통 조건

| 항목 | 조건 |
| --- | --- |
| 자료 | BEIR로 배포된 Natural Questions, 영어 |
| 평가 구간 | 토큰화 안정 조건을 통과한 최종 60개 구간 |
| 정답 범위 | 구간당 136개 위치, 합계 8,160개 토큰 위치 |
| 중첩 입력 | 내용 토큰 31+EOS=32 위치, stride 15, overlap 16 |
| 관측 수 | 구간당 8개 중첩 view |
| 모델 | GTR-T5-base 및 공개 GTR/NQ Vec2Text inverter/corrector |
| 추론 조건 | 50 correction steps, sequence-beam width 8, view별 Top-1 |
| 결합 입력 | 복원 결과·기존 점수·알려진 순서/geometry |
| 정답 사용 | 입력 안정성 검증 및 사후 평가·진단 |

여기서 “8개 복원 결과”는 서로 다른 중첩 입력의 Top-1을 뜻합니다. 한 입력의 beam 후보 8개를 뜻하지 않습니다.

## 네 가지 결합 출력

논문 Table 4(PDF 15쪽) 및 저장된 기존 집계 요약에서 가져온 값입니다.

| 방식 | matches / 8,160 | 복원율 | 치환 S | 삽입 I | 삭제 D | 총 편집량 E | 완전일치 구간 / 60 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| FC–L | 7,823 | 95.87% | 243 | 78 | 94 | 415 | 26 |
| FC–F | 8,045 | 98.59% | 79 | 22 | 36 | 137 | 38 |
| CP–L | 7,861 | 96.34% | 228 | 84 | 71 | 383 | 26 |
| CP–F | 8,061 | 98.79% | 70 | 41 | 29 | 140 | 35 |

FC는 고정 좌표 방식, L은 낮은 index 우선, F는 해당 view의 기존 점수 기반 선택입니다. CP–L은 원래 인접 후보쌍, CP–F는 누적 출력과 다음 후보를 경계 입력으로 사용합니다.

## 무엇의 효과를 비교했는가

### FC–L → FC–F: 선택 규칙만 변경

같은 8개 복원 결과, 좌표·clipping·빈 위치·길이·동률 규칙을 유지했습니다.

```text
복원율 차이 = (8,045 − 7,823) / 8,160 × 100 = +2.720588%p
총 편집량 차이 = 137 − 415 = −278개
```

동일 최종 60개 표본에 대해 나중에 추가한 **사후 탐색 분석**입니다. 같은 고정 출력에서 규칙을 바꾼 결과이며 새로운 독립 평가나 실제 배포 환경의 인과 효과로 해석하지 않습니다.

### FC–F → CP–F: 전체 방식과 상충관계

matches는 +16개(+0.196078%p)지만 삽입은 +19개, 총 편집량은 +3개입니다. 구간 완전일치는 38/60→35/60으로 감소했습니다. 경계 추정·길이 처리도 함께 달라져 정렬만의 독립 효과가 아닙니다.

### 다른 비교와의 구분

CP–F 대 CP–L은 owner와 왼쪽 경계 입력이 함께 달라지는 전체 방식 비교입니다. 원래 고정된 주 비교인 overlap/no-overlap도 8개 대 5개 벡터, 관측 중복과 입력 구성이 달라져 동일 예산의 overlap 효과가 아닙니다. 이 결과들을 FC의 +2.72%p와 합산하지 않습니다.

## 지표의 뜻

M=정확히 맞춘 정답 위치, N=정답 위치, S=치환, I=삽입, D=삭제로 두면 다음 관계가 성립합니다.

```text
복원율 = M / N
M + S + D = N
총 편집량 E = S + I + D
출력 길이 = M + S + I
```

단위 비용 Levenshtein 정렬의 결정적 traceback으로 대응을 정합니다. 복원율은 삽입을 직접 벌점화하지 않아 다른 오류 지표를 함께 확인해야 합니다. 구간 완전일치는 선택된 136-token 구간에 대한 값이며 전체 원문 문서의 완전 복원율과 다릅니다.

## 한계

- 원고는 길이 적합 문서 369개 중 210개가 안정 조건을 만족했다고 보고합니다. 이 통제된 부분집합의 결과를 모든 NQ 문서나 불안정 입력으로 확장하지 않습니다.
- assembly 평가에서 보류한 구간이라는 사실이 Vec2Text 학습 자료와의 비중복을 뜻하지 않습니다. 학습 자료 포함 여부는 미확인입니다.
- 정답 원문을 쓰는 selector·oracle·경계 진단은 실제 원문 미참조 결합 출력과 구분합니다.
- 다른 encoder·언어·geometry·실서비스에 적용하려면 추가 평가가 필요합니다.
- 공개 수치는 논문과 저장된 집계 요약을 기준으로 정리했습니다. 검산 명령은 집계 산술과 파일 일관성을 검사합니다.
